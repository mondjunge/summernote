List Exit: insertBreak vs insertParagraph

Both editors contain a list. Place the cursor in the last (empty) list item and press Enter. Observe the DOM output to see the difference.

To create an empty last item: click into the last list item and delete all text, or simply press Enter once on an existing item to get a new empty one, then Enter again to exit.

ENTER → insertBreak

keyMap.pc['ENTER'] = 'insertBreak'

Exiting an empty list item inserts <br>​ (BR + ZWS) directly — no wrapping <p>.

ENTER → insertParagraph (default)

keyMap.pc['ENTER'] = 'insertParagraph'

Exiting an empty list item creates a <p><br></p> block element after the list.
